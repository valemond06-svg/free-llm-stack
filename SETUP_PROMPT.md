# Prompt di setup

1. Clona il repo e aprilo:
   ```bash
   git clone <URL-DEL-REPO> free-llm-stack
   cd free-llm-stack
   claude
   ```
2. Incolla questo:

```text
Questo repo è un'infrastruttura LLM gratuita (FreeLLMAPI + bridge Antigravity + integrazione
Claude Code). Leggi CLAUDE.md e i documenti in docs/, poi guidami nel setup completo seguendo le
fasi di CLAUDE.md. Inizia con le domande della Fase 0, spiegami ogni passo in modo semplice,
dimmi tu cosa devo cliccare quando serve una registrazione o un login, e verifica ogni fase con
scripts/doctor.py prima di andare avanti. Non scrivere mai le mie key nei file del repo.
```
